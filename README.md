# Medya Promosyon

MEDAY için geliştirilmiş, Firebase ile entegre Next.js promosyon ürünleri kataloğu ve yönetim paneli.

## Özellikler

- Promosyon, matbaa ve iş elbiseleri ürün kataloğu
- Firebase Authentication ile korunan yönetim paneli
- Firestore ürün, teklif ve site ayarları yönetimi
- Firebase Analytics ve çerez onayı
- Teklif listesi ve iletişim formu
- Mobil uyumlu, erişilebilir arayüz
- SEO, sitemap, robots.txt ve llms.txt

## Geliştirme

```bash
npm install
npm run dev
```

Gerekli Firebase ve yönetici değişkenleri için `.env.example` dosyasını kullanın. Firebase servis hesabı dosyaları repoya eklenmez.
